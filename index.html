Revisions

When revision mode is on, every line you change is marked with * in the margin, in the color of the current revision – just like production drafts (White, Blue, Pink, Yellow…).

Drafts

Save the script as it is now (e.g. “First draft”), then keep writing. Compare any saved draft with the current script to see exactly what changed.

🎭 Table read

Hear your script read aloud with a different voice for each character – the best way to catch clunky dialogue. Uses the voices installed on your computer.
